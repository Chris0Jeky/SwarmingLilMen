Ecogenesis model notes

Ecogenesis is an artificial-life sandbox, not a calibrated biological forecast. Organisms inherit morphology, diet, thermal niche, defence, immunity, reproductive strategy and a tiny neural controller. Selection follows from energy acquisition, survival and reproduction inside a procedurally generated seasonal world.

The simulation advances in explicit phases:

environment → spatial index → bounded observations → neural intents
→ proportional resource allocation → kinematics/metabolism
→ simultaneous damage → disease → reproduction → death/nutrient return
→ metrics, lineage and rendering

Plants convert an external growth budget into biomass. Grazing and scavenging transfer that biomass into organisms. Death returns biomass as carrion, which decays into soil nutrients. Because sunlight and background nutrient regeneration are external inputs, this is not a closed mass-conserving chemistry.

“Species” are online genome clusters maintained for observation. They are useful for detecting lineage splitting but are not formal biological species. Neural controllers begin from viable heuristics and then mutate and recombine; this supports adaptation without claiming open-ended intelligence.

Determinism is scoped to this exact JavaScript implementation and browser/runtime. Floating-point, canvas and platform differences are not promised to be bit-identical across browsers. The displayed fingerprint covers every value that can influence future simulation evolution; it is an FNV-1a run fingerprint, not a cryptographic signature.
